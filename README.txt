VERCEL IMAGE API

Deploy this folder to Vercel.

Image endpoint:
https://YOUR-DOMAIN.vercel.app/download?file=b4fba8725929e044.jpg&type=images

Included image:
public/images/b4fba8725929e044.jpg

To add more images, put them inside public/images/.
Then use the exact filename in the file parameter.

Important:
Vercel serverless storage is not a permanent upload disk. This package serves
images included in the deployment. For a permanent web upload system, use
Vercel Blob or another object-storage service.
